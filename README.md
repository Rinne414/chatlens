# ChatLens

本地群聊阅读工具：在后台整理新消息，打开时就是一份「上次看完之后发生了什么」的简报。支持 Windows 和 Linux。

- **只读**：只读取本机聊天客户端数据库的副本，不发消息，不改动客户端的任何文件，也不标记已读。
- **本地**：控制台只在这台电脑上运行。不开 AI 时，聊天内容不会离开这台电脑。

## 能做什么

- **简报**：@你和回复你的消息、你关注的词、各群这段时间「值得知道的事」（几个群都在讲的合成一件，按分量排）、新东西和问答。
- **回顾**：按日期翻看任意一天，搜某个话题在哪几天聊过；也有周报和月报。
- **问群聊**：直接提问，AI 只根据本机的聊天记录回答，并附上出处。
- **群页**：消息量、在聊什么、谁和谁常来往。
- **画廊和咒语库**：群里的图片按天浏览；AI 图的生成参数（A1111 / Forge / ComfyUI / NovelAI）整理成可以搜索的库。
- **备份**：把图片、文件和聊天记录按群和月份存到你选的文件夹，逐个核对 md5。
- **Obsidian 笔记库（可选）**：把群里整理出的东西按主题写成 Obsidian 笔记，另有日报和每个群的笔记；你在「我的笔记」下写的内容不会被改。

AI 总结是可选的，可以用任意 OpenAI 兼容的 API（包括本机运行的 Ollama），或 Grok 订阅。

## 安装

从 [Releases](https://github.com/Rinne414/chatlens/releases) 下载：

- Windows：`chatlens-vX.Y.Z-win-x64.zip`，解压后双击 `Start-ChatLens.cmd`。
- Linux：`chatlens-vX.Y.Z-linux-x64.tar.gz`，解压后运行 `./start.sh`。

发行包自带运行环境。第一次启动后，开始菜单 / 应用菜单里会有快捷方式，也可以在「设置 → 快捷方式」放一个到桌面。有新版本时，左侧栏会出现「有新版本」，点一下就能一键更新。

从源码运行需要 Node.js 20+：

```sh
git clone https://github.com/Rinne414/chatlens
cd chatlens
npm install
npm start
```

浏览器会打开 `http://127.0.0.1:8321`。控制台在后台运行，关掉浏览器也不会停；要停止，点左侧栏最下面的「关闭控制台」。

Linux 版目前只在模拟数据上完整测试过，遇到问题欢迎开 issue。

## 第一次设置

第一次打开时，简报页就是「开始使用」引导，按顺序点完就能用：

1. **找到数据库**：点「自动查找」。电脑上有多个账号时可以直接切换。
2. **读取密钥**：先打开并登录聊天客户端，再点「自动获取密钥」。工具只读地查看本机客户端进程的内存来找出密钥，用你自己的数据库验证后加密保存（Windows 用 DPAPI，Linux 优先用系统钥匙圈）。Linux 上需要管理员权限，会弹出系统密码框。
3. **选要看的群**：密钥保存后自动读出你加入的群，搜索、勾选即可。以后在左边「关注的群」旁点「管理」随时增减；新加入的群会自动出现。
4. **AI 总结（可选）**：在设置页填 API 地址和 key 并选一个模型，或用 Grok 订阅登录。不填也能看消息、图片、热点和搜索。

所有设置也都在「设置」页。想开机就在后台准备好，打开「后台与通知 → 开机后在后台运行」。

## 数据与隐私

- 数据都只存在本机（`store/`、`runs/`、`reports/`），已被 `.gitignore` 排除。
- 控制台只监听 `127.0.0.1`，每次启动生成随机访问令牌。
- 会联网的只有：头像和群图片（从聊天客户端的图片服务器读取，设置页可以关掉）、你配置的 AI 服务（开启 AI 时发送要整理的消息文本），以及检查更新（GitHub）。
- 开启 AI 时，消息由你选的服务商按它的隐私政策处理。不想发出去，就不配置 AI，或用本机运行的模型。
- Obsidian 笔记库只在你选的文件夹里写本地文件；那个文件夹如果被 Obsidian Sync、网盘或 Git 同步，笔记会跟着上传。
- 一键更新只安装签过名的版本：签名或文件哈希对不上就拒绝安装。

## 负责任使用

- **只用在你自己所在的群**，只读这台电脑上你自己账号的数据。
- **不要拿来针对个人**：关系网和个人页是为了看懂群里的来往，不是为了跟踪、记录或骚扰某个人，也不要把这些页面截图外传。
- **别人的消息留在本地**：不要公开、转卖或上传别人的聊天、图片和 AI 总结。
