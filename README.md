# QQ 群消息简报（ChatLens · QQNT Read-only Summary Toolkit）

不打开 QQ，也能看完所有群消息：工具在后台自动收新消息、自动交给 AI 整理，你打开它时，一份「上次看完之后发生了什么」的简报已经准备好——谁 @ 了你、有什么新东西、大家问了什么又得到什么答案、哪几张图被求 tag，各群一句话说清楚。支持 **Windows 和 Linux**。

**核心原则：本地只读、零聊天操作。** 工具只读取 QQNT 的本地数据库做解析，不打开群窗口、不标记 QQ 已读、不使用 QQ 登录协议、不发送消息，也不修改任何 QQ 文件。「自动获取密钥」会**只读地**读取本机 QQ 进程内存以取出数据库密钥（不注入代码、不修改 QQ），是一次性本地操作。

## 功能

- **简报（首页）**：打开就能看，不用选群、选时间、等进度条。
  - **和你有关**：@你、回复你的消息（附上你原来说的那句）、@全体成员、提到你昵称的消息，点一下跳到聊天原位置。你是谁由 QQ 数据库里「自己发的消息」自动识别，不需要填 QQ 号。
  - **值得一看**：跨群汇总的「新东西」（新模型、工具、教程、资源、新闻，带原链接）、「问答」（有人问、有人答的问题，可以当知识看）、「大家在聊」（热门讨论）。
  - **好图**：这段时间群里的 AI 作品，被「求 tag / 看看原图」越多的排越前。
  - **各群**：每个群一两句话的总结和话题标签，点进去从上次看到的位置继续。
  - 「看完了」：下一份简报只包含之后的新消息。
  - 顶部的搜索框直接跳到「回顾」，搜哪天聊过某个话题。
- **回顾**：按日期翻看任意一天——日历上看出哪天消息多、哪天已有 AI 整理；点一天就是那天的「报纸」：各群按时间线列出聊了什么、那天的新东西和问答，点任意一段跳到当时的聊天。**话题搜索**同时搜 AI 整理和原文，按日期列出「这个话题在哪几天聊过」。浏览和搜索都只读已有的总结，不花 AI 费用；没整理过的日子可以一键「补齐」，显示预计调用次数和费用。
- **后台自动整理**：控制台在后台运行（可开机自动启动，不弹窗口），默认每 15 分钟收一次新消息；某个群攒够约 400 条、或最早一条等了 1 小时，就把这一段交给 AI 总结。**每条消息只总结一次**，结果缓存；各群总览最多每 2 小时重写一次。设置页的「AI 用量与费用」按服务商返回的 token 数统计实际花费，可以暂停 AI、设每日预算；另有每日调用上限兜底。
- **AI 用量与费用**（设置页）：按服务商每次返回的 token 数统计今天 / 7 天 / 30 天的花费和每日柱状图，按你自己群的数据算出「每 1000 条消息约多少钱」和每月估算；可暂停 AI（1 小时 / 到今天结束 / 一直）、设每日预算、调整总览重写频率和零散消息的等待时间；常用服务（DeepSeek、Gemini、通义千问、Kimi、SiliconFlow、OpenRouter、本地 Ollama）一键填入，并说明怎么选。价格表可编辑。
- **提醒**（可关）：有人 @ 你或回复你时弹系统通知；每天 9 点后推送一次简报摘要。Windows 用系统通知，Linux 用 `notify-send`。
- **像 App 一样用**：开始菜单 / 应用菜单里的「QQ 群消息简报」（Windows 快捷键 Ctrl+Alt+U）；在 Chrome / Edge 里「安装」后是独立窗口，任务栏图标会显示 @ 你的数量。
- **左侧栏**：每个页面都能看到关注的群——未读数、有人 @你 或回复你时的红点（点进群页），以及后台上次更新时间、今天的消息和 AI 图数量、快过期的 AI 原图提醒。
- **热点**：同一件事在好几个群里被提到时（新模型、工具、新闻、同一个链接、同一张图）列成一张卡：谁在哪个群先说的（首发）、怎么传到其他群（按时间的传播条）、各群怎么说（并排对比）。相近的名字（如 qwen / Qwen Image 2.1）合成一条。只用已有的消息和 AI 总结计算，不花 AI 费用。
- **群**：专看一个群——最近 30 天每天的消息量、一周里什么时候最热闹、每天聊了什么（点一条跳到那段消息）、最能聊 / 发图最多 / 最会回答的人、本群常用模型和 LoRA（和上周比）、最近的 AI 图、问答和分享的链接。
- **消息**：QQ 式群列表 + Telegram 式气泡聊天，本工具自己的已读进度；群列表显示每个群正在聊的话题，可以只看「有人 @我」「有新 AI 图」「有问答」的群；聊天里 @你 的消息和提问会标出来，可以只看图片，右侧可以打开「本群摘要」按 AI 整理的段落跳转；右键选中一段消息可单独做 AI 总结。
- **自定义总结与报告**：任选群和时间范围生成话题 / 时间线 / 新东西 / 问答报告；覆盖时间表区分「已扫描有消息 / 已扫描无消息 / 无扫描记录」，缺口可一键补扫（后台刷新也会自动补上最近 7 天内关注群的缺口）。
- **画廊**：后台记录下来的全部群图片（最近 31 天，含表情包），网格或瀑布流、大小可调，按天分段；左边按类型、群、发图人筛选（带数量），可以只看 AI 图，或按「传得最广」排序。图上标出 AI 来源（ComfyUI / NovelAI / A1111）、传到几个群、几人求过、快过期。点开看大图、它在哪些群出现过（首发和传播路径）、有参数就显示咒语、这个人的其他图和前后的聊天。「多选」后可以把原图导出到文件夹（按「时间_群_发图人」命名，带咒语的 AI 图附同名 .txt；腾讯只保留 31 天，更早的取不到原图）。
- **咒语库（AIGC 群专用）**：从 QQ 图片缓存读出 AI 生成参数（A1111 / Forge / ComfyUI / NovelAI），建成可搜索的 prompt / 模型 / LoRA 库，并配对 `kkt` / `kko` / 「求tag」这类请求；左边按范围、来源、模型、LoRA、群、发图人筛选（每项带张数），搜索条件显示成可以一键去掉的标签；网格 / 瀑布流 / 详细三种看法，支持训练集格式导出。详情页左边是原图、右边是咒语、参数、LoRA、谁求过这张图和回复，以及「同一作者的其他图」「同模型 / LoRA 的图」。注意：参数只在原图里——发图的人要勾选「原图」（否则 QQ 会压缩掉参数），而电脑 QQ 只保存你在电脑上点开过大图的原图，没有「全部自动下载」的开关。从 v0.0.13 起工具会自己去腾讯取图检查（见下面「群图片」），不用再在 QQ 里一张张点开。
- **备份（清理 QQ 前先存到电脑）**：页面顶部先告诉你有多少 AI 原图快过期、上次备份是什么时候、存到哪里；快过期的 AI 原图可以一键全部保存，也可以勾选几张导出到文件夹。整批备份分四步：选群、时间和内容（AI 图、被求过的图、其他图片、视频、文件、语音、表情、聊天记录），先扫描看数量、占用和电脑上缺哪些，再保存到你的文件夹：按「群 / 年-月」存放，AI 图旁边附一份咒语和参数的 .txt，聊天记录每天一个文本文件，附 Excel 可打开的清单。只有 md5 核对过的原图才算备份成功，缩略图和 QQ 压缩版会标出来并在下次补原图；再次运行只补新的。结果页直接告诉你「可以放心清理」还是「还缺哪些、怎么补」。电脑 QQ 只保存你在电脑上看过的图（点开大图才有原图），所以可选从 QQ 图片服务器按 md5 补下载电脑上没有的群图片（实测三天前的缺图能补回约三分之一，越旧越少）。工具从不删除 QQ 里的任何东西。
- **群图片（不用在 QQ 里点开）**：腾讯只保留群图片 31 天。这段时间里工具会自己去腾讯取图：
  - 消息里能直接看到每张图的缩略图，点开看大图或原图；表情包显示成表情图（动图点一下播放，小图每张约 17 KB）；
  - 带生成参数的 AI 图会自动记下咒语、参数和完整工作流（可下载 JSON 拖回 ComfyUI），并留一张较大的预览（腾讯给的尺寸，最宽 1280px，PNG 每张约 1–3 MB）；
  - 原图默认不留，点「保存原图」或把群设为「每张都留原图」才会永久保存；「备份」页会列出快过期、还没保存原图的 AI 图，可一键全部保存。
  - 图片占用有上限（设置页可选 2–100 GB，默认 10 GB），到上限先清普通图的缩略图，再从最旧的 AI 图预览清起，已保存的原图不会被清。实测 18 个群一个月：缩略图约 2 GB，AI 图预览约 5–8 GB。
  - 大多数群图片要用 QQ 临时发放的下载钥匙（约一小时有效），工具从正在运行的 QQ 内存里只读地取得，只放在内存里，不写入硬盘或日志——所以要 QQ 开着才能取图。Linux 上默认没有读取 QQ 内存的权限，取不到钥匙时只能按 md5 补下载（约三成）。设置页可以关掉「自动抓取群图片」。
- **存储页**：分开显示 QQ 原始数据库、数据库镜像、消息库、咒语库、运行产物和报告的占用与删除影响。
- 夜间模式、真实头像。

## 环境要求

- **Windows 10 / 11**，或 **Linux x64**（官方 QQ for Linux 3.x，原生包 / AppImage / Flatpak 均可；用 Wine 跑的 Windows QQ 不支持）。
- **QQNT 新架构版 QQ**（本地数据库为 `nt_db` 下的 SQLCipher 加密 SQLite）。经典架构老版本 QQ 不支持。
- 发行版压缩包自带运行环境；从源码运行需要 **Node.js 20+**。
- 磁盘：会保留一份 QQ 消息数据库的只读镜像（体积与 QQ 数据库相当），换来每次刷新只需几秒。
- 可选：任意 OpenAI 兼容的 LLM API（DeepSeek / OpenAI / 本地 Ollama 等），不配置则只有统计和「和你有关」，没有 AI 总结。

## 安装

从 [Releases](https://github.com/Rinne414/chatlens/releases) 下载：

- Windows：`chatlens-vX.Y.Z-win-x64.zip`，解压后双击 `Start-QQ-Console.cmd`。
- Linux：`chatlens-vX.Y.Z-linux-x64.tar.gz`，`tar -xzf` 解压后运行 `./start.sh`。

第一次启动后，开始菜单 / 应用菜单里会出现「QQ 群消息简报」，以后从那里打开即可。

或从源码运行：

```sh
git clone https://github.com/Rinne414/chatlens
cd chatlens
npm install
npm start          # Windows 也可以双击 Start-QQ-Console.cmd，Linux 也可以 ./start.sh
```

浏览器会打开 `http://127.0.0.1:8321`。控制台在后台运行，关掉浏览器也不会停；需要停止时到「设置 → 后台与通知 → 停止后台服务」。

## 首次配置（「设置」页）

1. **QQ 数据库路径**：点「自动探测并保存」。
   - Windows 默认在 `...\Tencent Files\<你的QQ号>\nt_qq\nt_db`（会扫描所有盘符）。
   - Linux 默认在 `~/.config/QQ/nt_qq_<一串字符>/nt_db`（Flatpak 版在 `~/.var/app/com.qq.QQ/config/QQ/...`）。多个账号时按最近使用排序。
2. **数据库密钥**：打开并登录 QQ，点「🔑 自动获取密钥」。工具从本机 QQ 进程内存里读出候选密钥，用你自己的数据库验证后保存（多核并行验证，一般十几秒到一两分钟）。
   - Linux 读取其他进程内存需要管理员权限，会弹出系统密码框（`pkexec`）；只运行一个只读的扫描脚本。没有 `pkexec` 时可以在终端运行 `sudo node src/linux_key_scan.js --output /tmp/qq-keys.txt` 后回来手动保存，或参考 [QQBackup/qq-win-db-key](https://github.com/QQBackup/qq-win-db-key) 手动取得密钥再粘贴。
   - 密钥保存位置：Windows 用 DPAPI 加密存在 `%APPDATA%\QQSummaryTools\`；Linux 优先存进系统钥匙圈（`secret-tool`），没有钥匙圈时存为 `~/.config/QQSummaryTools/` 下权限 0600 的文件。都不会进项目目录或 Git。
3. **LLM（可选）**：填 API 地址与 key，点「获取模型列表」选一个模型。
4. 在「设置 → 更多 → 关注群」勾选常看的群。之后打开「简报」就行了；想开机就在后台准备好，打开「后台与通知 → 开机后在后台运行」。

## 常见问题

- **腾讯能发现我在用这个工具吗？** 消息读取、AI 整理和「自动获取密钥」都只在本机进行，不登录 QQ 协议、不发送消息，也不会打开群或修改 QQ 已读状态。浏览器加载头像，以及媒体导出在本地缓存缺失时补齐旧式群图片，会访问腾讯公开 CDN。
- **消息内容会被发到哪里？** 默认哪里都不发。只有开启 AI 总结时，消息文本会发送到**你自己配置**的 LLM 服务；介意就不配 LLM key（或在「后台与通知」里关掉自动 AI 总结）。
- **后台会不会一直花 AI 的钱？** 每条消息只总结一次，没有新消息就不调用；每天还有调用上限（默认 400 次）。设置页能看到今天用了多少次。
- **Linux 版测过吗？** Linux 版的完整流程（路径探测、密钥扫描与验证、数据库镜像、导出、后台刷新、简报、启动器、更新）已在 Ubuntu 24.04 上用模拟的 QQNT 加密数据库跑通；真实的 Linux QQ 数据还需要更多用户验证，遇到问题欢迎提 issue（附上设置页的错误提示即可，不要贴密钥和聊天内容）。
- **QQ 更新后失效？** QQNT 大版本更新可能改变数据库结构或密钥获取方式，届时需要等待适配。

## 数据与隐私

- 所有产物都只在本机，均已被 `.gitignore` 排除：消息库 `store\messages.db`、数据库镜像 `store\db-mirror`、咒语库 `store\knowledge.db`、扫描产物 `runs\`、报告 `reports\`。
- 数据库镜像是 QQ 消息库的只读副本，只由工具自己的同步程序写入；删除后下一次刷新会重新复制一次。
- 本地消息库永久保留，不会被自动清理。需要释放空间时请用「存储」页。
- 控制台只监听 `127.0.0.1`，每次启动生成随机访问令牌，拒绝非本机 Host。
- 会联网的只有：头像、群图片（腾讯的 `multimedia.nt.qq.com.cn` 和 `gchat.qpic.cn`，只取你关注群里出现的图；设置页可关掉自动抓取）和「本机缺原图时补下载群图片」（按 md5 校验；备份页默认打勾，可以取消）、你配置的 LLM 服务（开启 AI 总结时发送消息文本）、「检查更新」（GitHub）。
- 取群图片用的下载钥匙从正在运行的 QQ 进程内存只读取得（和自动获取数据库密钥是同一类读取），只保存在控制台进程的内存里，从不写入硬盘、日志或网页。
- 备份文件夹由你选择，工具只往里面写，不会写进 QQ 自己的目录，也从不删除 QQ 里的任何东西。
- 「一键更新」只安装作者签过名的版本：每个发布都附带安装包的 SHA256 清单和 Ed25519 签名，程序用随附的公钥（`update-signing-public.pem`）校验签名和文件哈希，任何一项不对就拒绝安装，并提示到发布页手动下载。就算 GitHub 账号被盗，别人也发不出能被自动安装的更新。

## 发布新版本（维护者）

一键更新只认签过名的版本，所以发布时多一步签名：

1. 第一次（每台电脑一次）：`node scripts/make_update_key.js` 生成签名钥匙。私钥加密保存在本机（Windows DPAPI / Linux 钥匙圈），不需要密码；桌面上会留一份备份，请移到 U 盘或网盘私人文件夹。换电脑后用 `node scripts/make_update_key.js --restore <备份文件>` 还原。
2. 每次发布：把安装包放进 `dist/` 后运行 `node scripts/sign_release.js dist <版本号>`，把生成的 `chatlens-v<版本号>-SHA256SUMS.txt` 和 `.sig` 与安装包一起上传。
3. 私钥弄丢了：已安装的程序会拒绝之后的自动更新，用户手动下载一次新版即可；然后重新生成钥匙，新公钥随新版发布。
